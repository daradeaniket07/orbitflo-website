# OrbitFlo website

## Stack

- Next.js 15 App Router, React 19, TypeScript, Tailwind CSS 4
- npm for package management
- Framer Motion for animation
- Next Font for Space Grotesk headings and Inter body text
- No additional runtime or development libraries without approval

## Structure

- `src/app/`: App Router pages, global styles, metadata routes
- `src/components/`: shared site header, footer, and visual components
- `src/config/site.ts`: central source for site identity, navigation, contact placeholders, and Home copy
- `src/config/services.ts`: central source for service sections, inclusions, package names, and package details; keep package enquiries amount-free
- `brand-source/`: original brand and supplied image artwork; keep source files intact
- `public/brand/`: optimized brand assets used by the site
- `public/images/`: optimized WebP site imagery; service image paths and descriptive alt text live in `src/config/services.ts`
- `public/`: static assets
- `src/app/globals.css`: design tokens, Tailwind theme mapping, and global responsive styling

## Conventions

- Keep brand colors in CSS custom properties in `src/app/globals.css`, mapped into Tailwind's theme there.
- Use `next/image` for supplied brand marks and page imagery; preserve originals in `brand-source/` and use optimized copies from `public/brand/` or `public/images/`.
- Keep repeated site copy, navigation, and contact values in `src/config/site.ts`; keep service and package content in `src/config/services.ts`.
- Use `[TODO]` markers for copy and contact information that has not been supplied. Do not invent client results or contact details.
- Build reusable UI in `src/components/`; route files should stay focused on page content and metadata.
- Use semantic HTML, keyboard-visible focus, mobile-first responsive layouts, and no horizontal overflow.
- Respect `prefers-reduced-motion` for all animation.
- Add page metadata for routes and keep sitemap, robots, and Organization structured data current.
- Keep search indexing disabled during development with root metadata `robots: { index: false, follow: false }`. At launch, remove the noindex metadata and add the sitemap line to `robots.txt`.
- Deployment workflow: after each task, run `npm run lint` and `npm run build`, commit with a clear message, and push to `main`. Every push deploys to the live site automatically; do not leave changes unpushed.
- For Home layout updates, regenerate and commit full-page screenshots at 1440×900, 1280×720, and 390×844 in `screenshots/`, overwriting the existing files.
- The root Open Graph image is generated by `src/app/opengraph-image.tsx` and reused for Twitter's `summary_large_image` card.
- `public/images/about-constellation.webp` is optimized and ready for the future About page; it is intentionally not placed yet.
- `public/images/og-background.jpg` is a compact ImageResponse-compatible source generated from the supplied OG artwork; the WebP version remains the general optimized asset.
- Prefer Next.js built-in features and avoid dependencies beyond the approved stack.
